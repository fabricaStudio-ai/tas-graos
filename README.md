## Como publicar na Vercel

1. Acesse https://vercel.com/new
2. Clique em "Import" e arraste esta pasta (ou faça upload do ZIP)
3. Clique em "Deploy"

Pronto! Em segundos sua página estará no ar.

Você também pode usar a CLI:

```
npm i -g vercel
vercel
```
